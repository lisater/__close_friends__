# Фабричный метод
Фабричный метод — это порождающий паттерн проектирования, который определяет общий интерфейс для создания объектов в суперклассе, позволяя подклассам изменять тип создаваемых объектов.

Суть: Паттерн Фабричный метод предлагает создавать объекты не напрямую, используя оператор new, а через вызов особого фабричного метода. Не пугайтесь, объекты всё равно будут создаваться при помощи new, но делать это будет фабричный метод.
2. В каких случаях используют?
- Когда заранее неизвестны типы и зависимости объектов, с которыми должен работать ваш код.
- Когда вы хотите дать возможность пользователям расширять части вашего фреймворка или библиотеки.
- Когда вы хотите экономить системные ресурсы, повторно используя уже созданные объекты, вместо порождения новых.

3. Ошибки при использовании
- Избыточность: Создание фабрики там, где достаточно обычного конструктора или простой функции.
Если у вас только один тип продукта и нет планов на расширение — фабрика только усложнит код.
- Взрыв классов: Каждый новый продукт требует создания нового класса-фабрики (ConcreteCreator). Это увеличивает количество файлов и сущностей в проекте .

Задача 4. Предметная область: «Оплата» (Финтех / e-commerce)
Условие:
Вам необходимо спроектировать систему обработки платежей. Система должна поддерживать три способа оплаты: Банковская карта (Card), Электронный кошелёк (Wallet) и Криптовалюта (Crypto).

Требования:

Создайте абстрактный класс Payment с методом pay(amount: float) -> str (возвращает строку — подтверждение оплаты).

Создайте классы CardPayment, WalletPayment, CryptoPayment, реализующие Payment.

Создайте абстрактный класс PaymentProcessor (создатель) с абстрактным методом create_payment() -> Payment. Добавьте метод process(amount: float), который вызывает create_payment() и затем pay(amount).

Создайте классы CardProcessor, WalletProcessor, CryptoProcessor.

Проверка: напишите функцию checkout(processor: PaymentProcessor, amount: float), которая принимает процессор и сумму, и возвращает строку об оплате. Проверьте на всех трёх процессорах.
