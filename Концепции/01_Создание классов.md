# Создание классов
В модели данных Python класс — это объект, экземпляр метакласса (по умолчанию type), 
который одновременно выполняет три функции:
1. Результатом вызова класса является создание экземпляра
2. Класс является хранилищем атрибутов, разделяемых экземплярами
3. Класс включает в себя набор специальных методов, реализующих протоколы языка

Экземпляр — объект, для которого type(obj) возвращает данный класс (см .Экземпляр)

## Механизм связи «класс ↔ экземпляр».
Реализуется через:
- слот ob_type (тип объекта, статически связан);
- __dict__ / дескрипторы (доступ к атрибутам и их переопределение).

## Ключевой принцип. 
Класс и экземпляр — объекты одной природы. 
Следствия:
- класс можно передать в функцию;
- класс можно поместить в коллекцию;
- класс можно изменить в рантайме.

Сравнение с другими языками.
Это отличает Python от Java/C++ и делает понятие «класс» вычислительным, а не декларативно-статическим.

## Тонкость. Конструктор и namespace
Слово «конструктор» в Python неоднозначно.
Создание экземпляра -__new__- выделяет и формирует экземпляр
Инициализация  - __init__ - настраивает уже созданный экземпляр

В Python каждый класс имеет собственное пространство имён (namespace) — это контейнер, где хранятся имена (идентификаторы) и связанные с ними объекты: атрибуты, методы и другие определения. 
Внутренне пространства имён в Python обычно реализуются как словари, где ключи — это имена, а значения — объекты. 
Ключевой принцип: имя — не объект. Имена живут в namespace, объекты — в памяти. Одно имя можно перепривязать к другому объекту; один объект может иметь много имён (a = b = obj).

Чтобы посмотреть, что находится в пространстве имён класса, можно воспользоваться атрибутом __dict__: 
```python
print(MyClass.__dict__)
```

### Задание
Создайте класс Animal. Пропишите в нём метод init, который сохраняет имя животного (self.name = name), и метод speak, который возвращает строку вида "{name} makes a sound"
#### 1 способ - классическое создание class
```python
class Animal: #исполнение тела класса как обычного кода в отдельном namespace
    kind = "animal"              # атрибут класса (кладёт "kind"->"animal") в namespace класса

    def __init__(self, name):    # инициализатор экземпляра (создаёт функцию и кладёт её в namespace под именем __init__)
        self.name = name         # атрибут экземпляра

    def speak(self):             # метод
        return f"{self.name} makes a sound"
    '''
    По завершении тела Python берёт собранный namespace и вызывает метакласс (по умолчанию type):
    Animal = type("Animal", (object,), ns) 
    «Возьми имя "Animal", базу object и словарь ns — и построй из них класс. Результат положи в переменную Animal.»
    '''

# 1) Создаём экземпляры: __init__ вызывается автоматически
cat = Animal("Cat")
dog = Animal("Dog")

# 2) Вызываем метод: self подставляется автоматически (bound method)
print(cat.speak())          # Cat makes a sound
print(dog.speak())          # Dog makes a sound

# 3) Атрибут класса доступен и через класс, и через экземпляр
print(Animal.kind)          # animal
print(cat.kind)             # animal  (найден через MRO в классе)
print(dog.kind)             # animal

# 4) Атрибуты экземпляра лежат в __dict__ самого объекта
print(cat.__dict__)         # {'name': 'Cat'}
print(dog.__dict__)         # {'name': 'Dog'}

# 5) Атрибуты класса лежат в __dict__ класса (не экземпляра)
print(Animal.__dict__.keys())   # dict_keys(['__module__', 'kind', '__init__', 'speak', ...])
```

#### 2 способ - эквивалентный способ
Его в основном используют для понимания материала, а реальности его почти не используют
Он служит своего рода "мостиком" для перехода от привычного нам программирования к ООП
```
def _init(self, name):
    self.name = name

def speak(self):
    return f"{self.name} makes a sound"

Animal = type(
    "Animal",                    # 1) имя класса → Animal.__name__
    (object,),                   # 2) базы → Animal.__bases__, MRO
    {                            # 3) namespace → Animal.__dict__
        "kind": "animal",
        "__init__": _init,
        "speak": speak,
    },
)
if __name__ == "__main__":
    print(f"Animal.kind = {Animal.kind}")  # animal
    cat = Animal("Cat")
    print(cat.speak())                     # Cat makes a sound
    print(cat.__dict__)                    # {'name': 'Cat'}
```

#### 3 способ - Метакласс (программируемый «конструктор классов»)

Используют, когда нужны фреймворки, где нужно перехватить сам процесс создания класса. Для прикладного кода — обычно избыточен

```python
class AnimalRegistry(type): #метакласс наследует type, т.е. сам является «классом классов»
    registry = {} #общий словарь на метаклассе: все классы пишут в одно место.

    # Метод создания класса. Вызывается автоматически, когда Python 
    # встречает инструкцию `class` для любого наследника.
    def __new__(mcls, name, bases, ns, **kwargs):
        # Создаём сам класс стандартным способом.
        # super() здесь — это type. Мы просим type создать класс.
        # mcls — это сам RegistryMeta (как self в обычных классах).
        cls = super().__new__(mcls, name, bases, ns, **kwargs)
        # Проверка: если имя создаваемого класса не "Base", то регистрируем его.
        if name != "Animal":
            # Кладём в словарь registry связку "имя класса" -> "сам объект класса".
            # Важно:мы обращаемся к mcls.registry (метаклассу), 
            # а не к cls.registry (классу)
            mcls.registry[name] = cls #возвращаем готовый класс
        return cls

class Animal(metaclass=AnimalRegistry):
    def __init__(self, name):
        self.name = name
        
    def speak(self):
        return "Some sound"

# Создаём наследников. Они АВТОМАТИЧЕСКИ попадут в реестр!
class Cat(Animal):
    def speak(self):
        return f"{self.name} says: Meow!"

class Dog(Animal):
    def speak(self):
        return f"{self.name} says: Woof!"

class Cow(Animal):
    def speak(self):
        return f"{self.name} says: Moo!"

if __name__ == "__main__":
    # Выведет: {'Cat': <class 'Cat'>, 'Dog': <class 'Dog'>, 'Cow': <class 'Cow'>}
    print(AnimalRegistry.registry)

    animal_type = "Dog"
    # Берём класс из реестра и создаём экземпляр
    AnimalClass = AnimalRegistry.registry[animal_type]
    my_pet = AnimalClass("Rex")
    
    print(f"Создан объект: {type(my_pet).__name__}")
    print(f"Его имя: {my_pet.name}")
    print(f"Он говорит: {my_pet.speak()}")
```
