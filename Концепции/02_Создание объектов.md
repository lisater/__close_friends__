# Создание объекта
В модели данных Python экземпляр — это объект, для которого type(obj) возвращает данный класс. 
В отличие от создания классов, создание экземпляров всегда идёт через один базовый механизм, но мы можем перехватить его на разных уровнях.

## Тонкость: создание vs инициализация

Слово «конструктор» в Python неоднозначно. В отличие от C++/Java, где конструктор — единая операция, в Python процесс разделён на две фазы:
- Создание (__new__) — выделяет память и формирует «пустой» экземпляр. Это статический метод, первым аргументом получает класс (cls), а не экземпляр. По умолчанию это object.__new__.
- Инициализация (__init__) — настраивает уже созданный экземпляр (заполняет __dict__). Получает экземпляр (self), ничего не возвращает (только None).

Ключевой принцип: __init__ — это не конструктор, а инициализатор. Создание и инициализация — разные операции. Если __new__ вернёт объект, не являющийся экземпляром данного класса, __init__ не будет вызван.

## Механизм вызова: type.__call__
Когда вы пишете Animal("Cat"), вы вызываете класс как объект. 
Поскольку класс сам является экземпляром метакласса (по умолчанию type), вызов Animal(...) транслируется в type.__call__(Animal, ...).
Этот вызов выполняет три шага:
- Animal.__new__(Animal, ...) — создаёт экземпляр.
- Animal.__init__(экземпляр, ...) — инициализирует его.
- Возвращает готовый экземпляр.

## Namespace экземпляра: где живут данные
Каждый экземпляр имеет собственное пространство имён — obj.__dict__. Это обычный словарь, куда попадают атрибуты, созданные в __init__ (например, self.name = name).

Ключевой принцип поиска атрибутов: при обращении cat.name Python ищет не по правилу LEGB (как в функциях), а по цепочке:
- cat.__dict__ (атрибуты экземпляра).
- Animal.__dict__ и далее по MRO (атрибуты класса).
Дескрипторы (например, property) имеют приоритет над __dict__ экземпляра.

Следствие: атрибуты экземпляра затеняют атрибуты класса, но не изменяют их. cat.kind = "cat" создаёт запись в cat.__dict__, не трогая Animal.kind.

1 способ - классический способ
"""python
class Animal:
    def __init__(self, name):
        self.name = name

cat = Animal("Cat")  # Вызов класса. 
"""

По шагам:
- Animal("Cat") → type.__call__(Animal, "Cat").
- Animal.__new__(Animal) создаёт пустой экземпляр.
- Animal.__init__(экземпляр, "Cat") записывает name в __dict__.
- Возвращается готовый cat.

Суть: работает стандартный механизм. Вы просто передаёте аргументы, которые попадут в __init__.

2 способ: создание пустого экземпляра
"""python
class Animal:
    def __init__(self, name):
        self.name = name
cat = object.__new__(Animal)  # создан, но __init__ НЕ вызван!
cat.name = "Cat"              # заполняем вручную
"""

3 способ: клонирование
"""python
class Animal:
    def __init__(self, name):
        self.name = name

import copy

#Python вызывает Animal.__new__ (создаёт пустой объект), 
#затем Animal.__init__ (записывает self.name = "Cat" в cat.__dict__). 
#Результат — объект cat с cat.__dict__ == {'name': 'Cat'}
cat = Animal("Cat")
cat_clone = copy.copy(cat)      # поверхностная копия
# смотрит на тип объекта cat (Animal)
# ищет метод __copy__. если есть - вызвает (нет0
# Для обычных объектов создаётся новый пустой экземпляр того же класса через object.__new__(Animal) — без вызова __init__
# В __dict__ нового объекта копируются ссылки на значения из cat.__dict__

cat_deep = copy.deepcopy(cat)   # глубокая копия 
# рекурсивно обходит все атрибуты объекта.
# Для каждого атрибута создаёт полную копию (рекурсивно).
# В __dict__ нового объекта записываются копии значений.


import pickle # Клонирование через pickle (сериализация)
# Импортирует модуль pickle, который умеет превращать объекты Python в поток байтов и обратно
data = pickle.dumps(cat)
#вызывает у объекта протокол сериализации
#По умолчанию для обычных объектов это сводится к __reduce__, который возвращает кортеж: (Animal, (), cat.__dict__) — то есть «вызови Animal без аргументов, затем обнови __dict__ этим словарём».
#pickle записывает в байты: имя класса, модуль, и содержимое __dict__.
#Возвращает bytes — поток байтов.


cat_from_bytes = pickle.loads(data)
#читает байты
"""

Поверхностная копия (Shallow Copy)
При таком копировании создаётся новый объект, и в него копируются значения примитивных полей (числа, строки, булевы значения) из оригинала. 
Однако если какое-то поле само является объектом (или массивом), то в новую копию записывается ссылка на тот же вложенный объект в памяти, что и в оригинале. 
Ключевой результат: оригинал и копия не независимы.

Глубокая копия (Deep Copy)
Здесь создаётся полностью новый и независимый объект.
Ключевой результат: любые изменения, внесённые в копию, никак не затронут оригинал, и наоборот.
