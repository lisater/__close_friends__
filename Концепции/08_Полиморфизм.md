#### Определение
**Полиморфизм** - концепция, которая позволяет разным сущностям выполнять одни и те же действия, использовать одни и те же методы. При этом неважно, как эти сущности устроены внутри и чем они различаются.
#### Пример использования
```python
class Student():  
    def __init__(self, name):  
        self.__name = name  # устанавливаем имя  
  
    @property  
    def name(self):  
        return self.__name  
  
    def study(self):  # этот метод будет использован другими классами  
        """Опишите метод в своём классе"""  
  
  
class Diligent(Student):  
    def study(self):  # учиться можно так  
        print(f"{self.name} начинает делать домашнее задание прямо сейчас.")  
  
  
class Lazy(Student):  
    def study(self):  # или так  
        print(f"{self.name} откладывает домашнее задание на завтра.")  
  
  
friend = Diligent('Полина')  
me = Lazy('Лиза')  
friend.study()  
me.study()
```

Этот результат показывает нам, что и объект `friend` и объект `me` используют метод `study`, хоть он реализован разными способами и объекты относятся к разным классам. 
Важно отметить, что в Python можно реализовать полиморфизм и без общего родительского класса (см. Duck Typing).
